# JobTracker MVP 设计

需求来源：用户明确要求 Windows Flutter 桌面、中文界面、完全本地数据与可运行发布目录。

## 架构

- `lib/data/models.dart`：不可变记录、日期运算和无响应提醒规则。
- `lib/data/database.dart`：SQLite schema v1、事务、外键和简历导入。
- `lib/app.dart`：工作台导航、页面共享数据和本地文件操作。
- `lib/ui/`：总览、列表、详情、表单及通用组件。
- `windows/`：原生窗口，默认 1280×820，最小 960×640（随 DPI 缩放）。

SQLite 使用 WAL、外键和事务。创建/修改记录及进度事件一起提交。采用参数化查询。无需网络或登录。首次运行创建空数据库，不混入演示数据。原生文件选择器与系统默认应用负责导入/打开简历。

## 业务规则

阶段：已投递、处理中、笔试、面试、Offer。状态：进行中、明确拒绝、主动放弃、已入职。

创建记录时写入初始事件。编辑阶段/状态时追加今天的事件；其他字段变化不重置进度时间。新事件限制在投递日至今天之间。补录按日期排序，同日按自增 ID 排序。最新实际进展决定当前阶段、状态与等待起点；仅跟进备注不改变三者。不能将投递日期改到已有事件之后。

等待天数按本地日历日期计算，负数钳制为零。进行中且非 Offer 的记录达到阈值时派生“长期无响应”提醒，无需修改数据库。应用每分钟及恢复前台时刷新视图。拒绝必须由用户明确填写。

简历保存名称、版本、导入时间、原始路径与本地副本引用；可关联到记录。删除简历记录解除关联但保留文件，以避免误删。删除求职记录级联删除其事件，弹窗确认。

## 范围

本版无云同步、邮件读取、网站抓取、移动端、自动更新或远程发布。数据不加密，依赖本机账户文件权限；关闭应用后完整复制数据目录备份。
