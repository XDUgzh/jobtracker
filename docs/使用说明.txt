JobTracker 1.0 — Windows 本地求职管理

开始使用
1. 如果收到 ZIP，请先完整解压。
2. 双击 jobtracker.exe。无需 Flutter、账号或服务器。
3. 在“简历库”导入 PDF / DOC / DOCX；在“新增投递”中关联简历。
4. 打开求职记录，点击“新增事件”记录笔试、面试和招聘反馈。

请保留 EXE 旁边的全部 DLL 以及 data 文件夹，它们是程序组成部分。
适用于 Windows 10/11 x64。发布目录已附带 Visual C++ 运行库。

记录规则
• “已投递”统计全部累计记录（删除的记录除外）。
• 笔试、面试、Offer 统计当前处于该阶段且仍在进行中的记录。
• 已结束包括明确拒绝、主动放弃、已入职。
• 长期无响应默认 14 天，可在偏好设置改为 7 / 14 / 21 / 30 / 60 天。
• 该提醒不代表拒绝，不会自动改变阶段或状态；Offer 和已结束记录不提醒。
• “新增事件”关闭“收到新的招聘进展”后，仅记录跟进备注，不重置等待天数。
• 历史事件按日期排序，同日以最后录入的进展为准。

数据与备份
默认目录：%LOCALAPPDATA%\JobTracker\data
可在应用“偏好设置”中查看实际路径并打开。
求职记录在 jobtracker.sqlite3，简历副本在 resumes 文件夹。
备份：先退出应用，再复制整个数据目录（包括可能存在的 -wal / -shm 文件）。
恢复：先退出应用、保留当前数据备份，再用完整备份替换数据目录。
应用目录与用户数据目录相互独立，更新程序无需删除数据目录。
删除简历记录会解除关联，但保留原文件及本地副本。

这是离线 MVP，招聘进度需要手动录入，不会读取邮箱或自动抓取招聘网站。
